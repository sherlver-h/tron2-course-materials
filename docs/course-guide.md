# TRON2 课程开发指南

课程采用一个公开 GitHub 仓库、六个小组目录的协作模式。35 名学生均通过仓库 Collaborator 邀请加入，获得仓库级写入权限。

每组可以同时使用 Python 与 C++：Python 源码放入 `src/python/`，C++ 源码放入 `src/cpp/`，头文件放入 `include/`，自动化测试放入 `tests/`，演示程序放入 `examples/`，说明文档放入 `docs/`，小型非敏感数据放入 `data/`。

小组目录只是提交约定。GitHub 个人仓库不提供按目录隔离 Collaborator 权限的机制，任何协作者都能修改整个仓库。
